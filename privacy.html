Privacy Policy

Last updated: 18 November 2026

Daily Story Uploader ("the app") is a private publishing tool operated by Hasintha Ranaweera. It uploads the daily videos of the channel owner's own YouTube channel. This policy explains how the app handles data.

YouTube API Services

The app uses YouTube API Services. By using the app, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information the app accesses

With the channel owner's permission, the app gets an OAuth token for the youtube.upload scope. It uses this token only to upload videos and their title, description and tags to the channel owner's YouTube channel. The app does not access any other data, such as viewer information, comments, analytics, email or contacts.

How information is stored

The OAuth token is stored as an encrypted secret in the owner's private GitHub repository. It is used only by the automated publishing job. The app does not collect personal data from viewers or other users, and it uses no cookies or tracking.

Sharing

The app does not sell, share or transfer any user data to third parties.

Revoking access

You can revoke the app's access at any time from your Google Account security settings at myaccount.google.com/permissions. When access is revoked, the stored token stops working. You can ask for any stored data to be deleted by email, and it will be deleted within 7 days.
